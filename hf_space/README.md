# spatio-textual Annotation Platform

This README is for the Hugging Face Space repository. Keep the main GitHub README clean and copy this file to the root of the HF Space only.

The default Docker image installs the lightweight `en_core_web_sm` spaCy pipeline.
Hugging Face and spaCy transformer choices appear only when their optional runtime
and model dependencies are installed.
